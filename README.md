# Python Mağaza Projesi 🛒🐍

Bu proje, **Python kullanarak geliştirdiğim bir mağaza uygulamasıdır**.  
Okul döneminde ödev olarak yapılmış ve Python dilinde temel programlama bilgilerini uygulamak amacı taşımaktadır.

---

## 🎯 Proje Amacı
- Basit bir mağaza sistemi oluşturmak  
- Ürün ekleme, listeleme ve yönetme işlemlerini Python ile gerçekleştirmek  
- Döngüler, fonksiyonlar ve veri yapıları (listeler, sözlükler) gibi Python konularını pekiştirmek  

> ⚠️ Not: Proje okul ödevi olarak yapılmıştır.  
> Hocamız, öğrendiğimiz tüm Python özelliklerini kullanmamızı istediği için kod yapısı biraz karışık olabilir.

---

## 🛠 Kullanılan Teknolojiler
- **Python 3**  
- Konsol tabanlı uygulama  

---

## 📂 Proje Özellikleri
- Ürün ekleme ve güncelleme  
- Ürünleri listeleme  
- Satış ve stok takibi  
- Döngüler ve kullanıcı menüsü ile interaktif kullanım
